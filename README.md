# 천산환경 AI 민원 자동 분석·관리 시스템

생활폐기물 수거 관련 민원을 자동으로 분석하고 관리하기 위한 Python 기반 시연용 웹 프로그램입니다.

## 1. 주요 기능

- 민원 텍스트 입력
- 행정동 및 세부 위치 추출
- 6개 민원 유형 규칙 기반 분류
- HIGH / MEDIUM / LOW 긴급도 판별
- 핵심 민원 내용 요약
- 현장 기사 전달 메시지 생성
- SQLite 데이터베이스 이력 관리
- 민원 처리 상태 변경
- 행정동별·유형별 통계 분석
- CSV 다운로드

## 2. 기술 스택

- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## 3. 설치 방법

Python 3.10 이상을 권장합니다.

```bash
pip install -r requirements.txt
```

## 4. 실행 방법

```bash
streamlit run app.py
```

브라우저에서 다음 주소로 접속합니다.

http://localhost:8501

## 5. 시연 방법

1. 대시보드에 접속합니다.
2. '시연용 가상 민원 27건 생성'을 클릭합니다.
3. 대시보드에서 민원 통계를 확인합니다.
4. 민원 접수 메뉴에서 테스트 민원을 입력합니다.
5. 자동 분석 결과를 확인합니다.
6. 분석 결과를 SQLite에 저장합니다.
7. 민원 관리 메뉴에서 처리 상태를 변경합니다.
8. 통계 및 분석 메뉴에서 결과를 확인합니다.

## 6. 데이터 안내

초기 시연 데이터는 실제 민원 원문이 아닌 가상 데이터입니다.

보고서에 제시된 2026년 10월 집계 결과를 재현하기 위한 목적으로 구성합니다.

- 총 27건
- 용현동 20건
- 숭의동 7건
- 지자체 경유 17건
- 재활용품 미수거 9건
- 음식물류 미수거 6건
- 중간집하지 악취 3건

개별 민원 내용과 기타 분류는 시연을 위한 가상 데이터입니다.

## 7. 분석 방식

외부 AI API를 사용하지 않는 키워드 기반 규칙 분류 방식입니다.

실제 운영 전에는 회사의 민원 분류 기준 및 현장 담당자 검토를 통해 규칙을 보완해야 합니다.
